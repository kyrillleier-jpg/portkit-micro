    How this page works

    The page holds only the bytes this project adds or changes, never 1010music's firmware. It checks your file's SHA-256 against the stock release, applies the changes in your browser, and checks the result's SHA-256 against the tested build before offering it. Nothing is uploaded. The same patch file works with blackbox-mod's apply.py.
